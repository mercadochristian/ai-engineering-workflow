How the workflow got lighter.

Lauren Tan’s talk made me ask which parts of my workflow actually help me catch mistakes.

Watch All Code Is Slop (Except Mine)

Plan and review by risk

Pick a route.

Low
Brief scope and focused checks.
Standard
Reviewed spec and independent review.
High
Detailed spec and review of affected boundaries.

Prevent repeat failures

Put the rule in the code.

When a serious mistake can recur, look for the smallest safeguard that catches it.

A type, a schema constraint, or a focused test can catch a mistake the next time it happens.

Verify the real behavior

Ride the whole route.

Follow the change through the code that actually uses it.

For a Save fix, check what the form sent, what was stored, and what the user saw.

Evidence so far

Keep checking the workflow.
