# Beans

Beans is the main orchestrator and the mascot from the
[workflow deck](../docs/workflow-deck/index.html). Each version keeps the same
silhouette and uses the expression and color from its slide.

| Expression | Try it on | Editable SVG | Transparent PNG |
| --- | --- | --- | --- |
| Classic (mint) | Introductions | [SVG](beans.svg) | [PNG](beans.png) |
| Side glance (blue) | Choices and next steps | [SVG](beans-glance.svg) | [PNG](beans-glance.png) |
| Focused (orange) | Troubleshooting | [SVG](beans-focused.svg) | [PNG](beans-focused.png) |
| Looking up (teal) | Walkthroughs and callouts | [SVG](beans-looking-up.svg) | [PNG](beans-looking-up.png) |
| Cheerful (lavender) | Wins and closing slides | [SVG](beans-cheerful.svg) | [PNG](beans-cheerful.png) |

Use the 512 × 512 PNGs in slides and documents. Use the SVGs for web graphics
and layouts that need to scale. Mint (`#9AF0D0`) with dark ink (`#141931`) is
Beans' default look. For decorative placements on the web, use empty alt text.
When introducing the mascot, use “Beans the robot.”
